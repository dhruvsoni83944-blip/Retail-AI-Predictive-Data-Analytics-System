# 📊 Retail AI Predictive Data Analytics System

## 🚀 Overview

The **Retail AI Predictive Data Analytics System** is an end-to-end Data Analytics and Machine Learning project developed during my internship at **Amdox Technologies**.

The project transforms raw retail transaction data into meaningful business insights using **Data Cleaning, Exploratory Data Analysis (EDA), Feature Engineering, RFM Customer Segmentation, Customer Churn Prediction, Revenue Forecasting, and Interactive Dashboard Development**.

---

## 🎯 Objectives

- Analyze and clean retail transaction data.
- Understand customer purchasing behavior.
- Perform Exploratory Data Analysis (EDA).
- Segment customers using RFM Analysis.
- Identify customers at risk of churn.
- Forecast future revenue trends.
- Analyze sales and product performance.
- Develop an interactive analytics dashboard.
- Support data-driven business decisions.

---

## 🔄 Project Workflow

Retail Dataset → Data Cleaning → Feature Engineering → Exploratory Data Analysis → RFM Analysis → Customer Churn Prediction → Revenue Forecasting → Interactive Dashboard

---

## 📂 Dataset

The project uses a retail transaction dataset containing:

- Invoice Number
- Product Description
- Quantity
- Invoice Date
- Unit Price
- Customer ID
- Country

### Data Preprocessing

The dataset was prepared by:

- Handling missing values
- Removing duplicate records
- Removing invalid transactions
- Converting columns to appropriate data types
- Creating analytical features

---

## 🧹 Data Cleaning

Data cleaning was performed to improve the quality and reliability of the dataset.

Major steps included:

- Handling missing Customer IDs
- Removing duplicate records
- Identifying invalid transactions
- Correcting data types
- Preparing the data for analysis

---

## ⚙️ Feature Engineering

New meaningful features were created from the existing transaction data.

### Revenue

Revenue = Quantity × Unit Price

### RFM Features

- **Recency** – How recently a customer made a purchase.
- **Frequency** – How frequently a customer makes purchases.
- **Monetary** – How much a customer spends.

These features were used for customer analysis and segmentation.

---

## 📈 Exploratory Data Analysis

EDA was performed to understand important patterns and trends in the retail dataset.

The analysis included:

- Customer purchasing behavior
- Revenue trends
- Sales distribution
- Product performance
- Customer distribution
- Transaction patterns

Visualizations such as **bar charts, histograms, and trend charts** were used to represent the findings.

---

## 👥 RFM Customer Segmentation

RFM stands for:

**Recency:** How recently a customer purchased.

**Frequency:** How often a customer purchased.

**Monetary:** How much a customer spent.

RFM analysis helps identify different customer groups such as:

- Loyal Customers
- High-Value Customers
- Regular Customers
- At-Risk Customers
- Inactive Customers

---

## 🤖 Customer Churn Prediction

Customer churn refers to customers who stop purchasing from a business.

The project uses customer-related features to identify customers who may be at risk of churning.

### Benefits

- Identify potentially inactive customers
- Support customer retention strategies
- Enable targeted offers
- Improve customer engagement
- Reduce potential customer loss

---

## 📊 Revenue Forecasting

Historical sales data was analyzed to understand revenue patterns and estimate future trends.

Revenue forecasting can support:

- Sales planning
